# 3D_ActionGame_CombatTest

三人称視点の剣アクションを試す Unity HDRP プロジェクトです。移動、連続攻撃、敵との戦闘、命中時の演出を確認できます。

## 始め方

Unity Hub で `3D_ActionGame_PlayerTest` フォルダーを Unity 6000.3.18f1 で開き、`Assets/SampleScene.unity` を開いて Play を押します。

シーンを作り直す場合は、Unity のメニューから **ActionStudy > Build Sample Scene** を選びます。

## 操作

| 操作 | キーボード / マウス | ゲームパッド |
|---|---|---|
| 移動 | WASD / 矢印キー | 左スティック |
| 視点 | マウス（演出パネルを閉じている時） | 右スティック |
| 攻撃 | J / 左クリック（パネル外） | □ / X |
| 演出パネル | Tab | Select |

## 制作について

このプロジェクトは、別途制作している個人制作プロジェクトの戦闘ロジックと一部機能を取り込み、新しいプロジェクトに合うよう生成 AI を使って調整したものです。
