# Wiki

このページでは、プロジェクトの始め方と主な機能を説明します。

## 始め方

Unity 6000.3.18f1 でプロジェクトを開き、`Assets/SampleScene.unity` を開いて Play を押します。

シーンを作り直す場合は、Unity のメニューから **ActionStudy > Build Sample Scene** を選びます。シーンと `Assets/ActionStudy/Generated` 内の素材が更新されます。

## 操作

| 操作 | キーボード / マウス | ゲームパッド |
|---|---|---|
| 移動 | WASD / 矢印キー | 左スティック |
| 視点 | マウス | 右スティック |
| 攻撃 | J / 左クリック | □ / X |
| 演出パネル | Tab | Select |

攻撃ボタンを続けて押すと、弱攻撃から強い攻撃へつながります。左クリックで攻撃する時は、演出パネルを閉じてください。

## 主な機能

- 慣性のある移動と三人称カメラ
- 5 段の剣コンボ、敵への向き直り、踏み込み
- 敵の HP 表示、ダメージ表示、コンボ数
- ヒットストップ、吹き飛び、カメラ揺れ、光や音などの命中演出
- Tab で開く演出パネル。個別の演出を切り替えて違いを確認できます

## 主なスクリプト

| フォルダー | 役割 |
|---|---|
| `Scripts/Player` | プレイヤーの移動、攻撃、ロックオン |
| `Scripts/Combat` | 攻撃ごとの威力やタイミング |
| `Scripts/Enemy` | 敵の体力、反応、出現 |
| `Scripts/HitFeel` | 命中時の時間、画面、音、振動の演出 |
| `Scripts/UI` | 演出切り替え、HP、ダメージ、コンボの表示 |
