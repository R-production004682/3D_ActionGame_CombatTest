# 戦闘の手触り

このプロジェクトでは、剣が当たった瞬間の反応を、時間・光・動き・画面の変化で伝えます。スライドで紹介した演出を実際に切り替えながら、攻撃の重さや見え方を比べられます。

## まずは同じ攻撃を比べる

Unity 6000.3.18f1 で `3D_ActionGame_PlayerTest` を開き、`Assets/SampleScene.unity` を再生します。起動時に演出パネルが表示されます。Tab で開閉し、パネルから演出を一つずつ ON / OFF にできます。

同じ敵に同じコンボを当てて、演出を一つずつ切り替えてみてください。どの演出が手応えや分かりやすさに関わっているか比べられます。設定はプレイ中だけ有効で、再生をやり直すと初期状態に戻ります。

## スライドで紹介している 7 つの演出

1. **ヒットストップ:** 攻撃が当たった瞬間、ゲーム内の時間を短く止めます。強い攻撃ほど長く止まり、重さが伝わります。

2. **ヒットエフェクト:** 命中した場所に火花や光を出します。攻撃の強さを目でも確かめられます。

3. **カメラシェイク:** 命中した瞬間に画面を揺らし、衝撃を伝えます。

4. **ダメージフラッシュ:** 攻撃を受けた敵を一瞬白く光らせます。敵が複数いても、当たった相手を見分けやすくします。

5. **のけぞりと揺れ戻り:** 敵の体を攻撃された方向へ傾け、揺らして元の姿勢へ戻します。押し戻しも加わり、攻撃が効いたことを動きで伝えます。

6. **予備動作と緩急:** 攻撃の前に少しためてから振り抜きます。動きに差をつけ、攻撃を鋭く、重く見せます。

7. **画面効果:** 大技の瞬間に画面をぼかし、ゆがませます。ここが決め技だと一目で分かるようにします。

## 気持ちよさを支える 3 つの考え方

- **押した瞬間に応える:** 先行入力や命中後のキャンセルで、次の操作を待たせません。
- **攻撃の重さで差をつける:** 弱攻撃から大技へ進むほど、ヒットストップや吹き飛ばしなどの演出を強めます。
- **何が起きたか分かる:** 光や敵の動きに、音・振動・HP ゲージ・ダメージ数値を組み合わせて命中を知らせます。

## ほかに使っている工夫

- 敵への向き直り、踏み込み、ロックオンで攻撃を当てやすくします。
- 体の傾きや走りの上下揺れ、剣の軌跡や足元の砂煙で動きを見せます。
- カメラの追従、速度に応じたズーム、攻撃時の画面調整で動きを追いやすくします。
- ヒット音、ゲームパッドの振動、HP ゲージ、ダメージ数値、コンボ数で戦況を伝えます。

## 操作

| 操作 | キーボード・マウス | ゲームパッド |
|---|---|---|
| 移動 | WASD / 矢印キー | 左スティック |
| 視点 | マウス（演出パネルを閉じた時） | 右スティック |
| 攻撃 | J / 左クリック | □ / X |
| ロックオン・解除 | Q / マウスホイールクリック | 右スティック押し込み |
| 演出パネル | Tab | Select |

演出パネルが表示されている間は、左クリックで攻撃できません。
