# ヒット演出と切り替え項目

このページでは、ゲーム中の演出パネルにある ON / OFF 項目をまとめています。各項目を切り替え、同じ攻撃を比べるためのページです。

## 「加算モーション」とは

元の動きを止めたり置き換えたりせず、その上に小さな揺れを足す動きです。このプロジェクトでは、被弾した敵の体をバネのように揺らします。敵の基本動作が続いていても、攻撃の勢いが伝わります。

似た演出との違いは次のとおりです。

| 演出 | 何が動くか | 役割 |
|---|---|---|
| ダメージモーション | 敵の体全体 | のけぞりや大きな傾きで、攻撃を受けたことを伝える |
| 加算モーション | 敵の体に重ねた小さな揺れ | 基本の動きを残したまま、衝撃の余韻を足す |
| モデルシェイク | 敵の見た目 | ヒットストップ中に短く細かく震わせ、止まった画面でも命中を伝える |
| 攻撃側の震え | プレイヤーの剣 | 刃が敵に当たった抵抗感を出す |

**二次モーション**も、元の動きに遅れてついてくる動きです。ここでは、体の向きや加速に剣が少し遅れて追従します。

**ヒットストップ**は命中した瞬間にゲーム内の時間を止める演出です。キャラクターの動きや剣筋は止まりますが、火花・画面効果・カメラやモデルの揺れ・音は実時間で動き続けます。

## 演出パネルの項目

起動時にパネルが表示されます。Tab で開閉できます。パネルを表示している間は、左クリックで攻撃できません。設定は再生中だけ有効で、Unity の再生をやり直すと初期状態へ戻ります。

### 命中時の演出

| 項目 | 内容 |
|---|---|
| ヒットエフェクト | 命中位置に火花・閃光・斬撃線などを出します。攻撃の強さで量や種類が変わり、火花は斬った方向へ飛びます。 |
| ヒット SE | 金属音を鳴らします。攻撃の強さで音を変え、再生ごとに音程を少しずらします。 |
| ヒットストップ | 命中の瞬間に時間を止めます。重い攻撃ほど長く、最強攻撃で敵を倒すとスローになります。 |
| ダメージモーション | 敵をのけぞらせます。かかしはその場で傾いて揺れ戻り、近づく敵は動きを止めます。最強攻撃で倒すと吹き飛びます。 |
| 加算モーション | 敵の基本動作に、小さなバネの揺れを重ねます。 |
| ノックバック | 敵を攻撃方向へ押し出します。かかしは位置を保って大きく傾きます。強攻撃以上ではプレイヤーも少し押し戻されます。 |
| モデルシェイク | ヒットストップ中、敵の見た目を画面と平行に細かく揺らします。 |
| カメラシェイク | 命中時にカメラを揺らします。攻撃が重いほど強くなります。 |
| ダメージフラッシュ | 命中した敵を一瞬白く光らせ、複数の敵の中でも当たった相手を見分けやすくします。 |
| パッド振動 | ゲームパッド接続時に振動します。強い攻撃ほど強く、長く振動します。 |
| 画面効果 | 強攻撃以上で色ずれ・画面のゆがみ・放射状のぼかしを出します。命中マークも表示します。 |

### 入力と攻撃のつながり

| 項目 | 内容 |
|---|---|
| 先行入力 | 攻撃中に押したボタンを約 0.35 秒覚え、次の段を出せる時に実行します。 |
| ヒット確定キャンセル | 攻撃が当たった時は、攻撃判定が終わると次の段へ進めます。空振り時は通常のコンボ受付時刻を使います。 |
| 移動キャンセル | 攻撃の後隙の後半から、移動入力で走り始められます。 |
| 吸い付き・踏み込み | 近くの敵へ向き直り、攻撃が届く距離まで踏み込みます。OFF では正面へ一定距離進みます。 |

### プレイヤーの動き

| 項目 | 内容 |
|---|---|
| 初速ブースト | 止まった状態からの加速を強め、走り出しを鋭くします。 |
| クイックターン | 逆方向へ入力した時に、素早く振り向きます。 |
| 体の傾き | 旋回で内側へ、加速で前へ、停止や切り返しで後ろへ傾きます。 |
| ランボブ | 歩幅に合わせて体が上下・左右に揺れます。 |
| 予備動作と緩急 | 剣を振る前にため、振り抜きを速く見せます。 |
| スクワッシュ＆ストレッチ | 振りかぶりで体を縮め、振り抜きで伸ばします。 |
| 剣の揺れ追従（二次モーション） | 旋回・加速・足取りに、剣が少し遅れてついてきます。 |
| 剣の軌跡 | 剣が通った場所に光の帯を残します。 |

### カメラ

| 項目 | 内容 |
|---|---|
| 追従の遅れ・先読み | カメラが少し遅れて追い、進行方向の先を映します。 |
| 速度ズーム | 速く走るとカメラを少し引き、周りを見やすくします。 |
| 自動回り込み | 視点を操作していない間に、カメラをプレイヤーの背後へ戻します。 |
| 攻撃フレーミング | 攻撃中、狙った敵が画面から外れないようカメラを寄せます。 |
| FOV パンチ | 強攻撃で一瞬ズームし、超強攻撃では画面を引いてから戻します。 |
| ロックオン | 敵を狙い続け、攻撃もその敵へ向けます。ロック中は対象を切り替えられます。 |

**FOV** はカメラに映る範囲です。FOV を狭めるとズームイン、広げるとズームアウトします。

### 移動・撃破・UI

| 項目 | 内容 |
|---|---|
| 足元の砂煙 | 走り出し・切り返し・急停止・全力疾走で砂煙を出します。 |
| スピードライン | 全力疾走や踏み込みで画面の外周に線を流し、速さを見せます。 |
| 攻撃側の震え | ヒットストップ中にプレイヤーの剣を細かく震わせます。 |
| 撃破の予兆 | 倒した敵の目の光を消し、一瞬止めてから倒します。撃破済みだと分かりやすくなります。 |
| HP ゲージ | HP が減った後、白い残りゲージを遅れて減らします。一撃の大きさが見えます。 |
| ダメージ数値 | 命中位置からダメージ値を浮かべます。攻撃の強さで大きさや色が変わります。 |
| コンボカウンター | 連続ヒット数と、コンボが切れるまでの時間を表示します。 |

### 検証用の項目

これらは効果の比較用です。「すべて ON」ボタンでは有効になりません。カテゴリー内の個別ボタンで切り替えます。

| 項目 | 内容 |
|---|---|
| 攻撃フレーム表示 | 予備動作・攻撃判定・後隙・次段の受付・移動キャンセル・ボタン入力の時刻を表示します。 |
| 入力遅延 +100 ms | 入力を 6 フレーム遅らせる例です。演出が同じでも操作の遅れが手触りを変えることを比べます。 |
| 先行入力 1 秒 | 早く押したボタンまで実行される例です。入力を長く覚えすぎると、止めたい時に攻撃が出ることを比べます。 |

## パラメータを調整する

攻撃ごとの数値や、火花・カメラ・砂煙などの調整項目は、[演出パラメータ一覧](https://github.com/R-production004682/3D_ActionGame_CombatTest/wiki/Effect-Parameters)にまとめています。

## 比べ方

1. 同じ敵に同じ攻撃を当てます。
2. 演出を一つだけ OFF にします。
3. 命中の分かりやすさ、攻撃の重さ、操作のつながりがどう変わるか見ます。
4. もう一度 ON にして、違いを確かめます。
